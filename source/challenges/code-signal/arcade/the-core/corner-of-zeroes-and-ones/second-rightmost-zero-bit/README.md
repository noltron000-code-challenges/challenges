# Challenge
Presented with an integer, find the 0-based position of the second rightmost zero bit in its binary representation (it is guaranteed that such a bit exists), counting from right to left.

Return the position of the found bit.

# Example
Given *37*, the output should be **8**.

Note that `37 = 0b100101`.
The second rightmost zero bit is at position *3* (0-based) from the right, in the binary representation of the input.
